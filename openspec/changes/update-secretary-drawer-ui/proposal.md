## Why
当前 Secretary 抽屉在实际使用中不够“驾驶室”：
- 对话区高度被限制（messages 只有一个很小窗口），长回复阅读非常不便。
- 对话内容不渲染 Markdown，且换行/段落表现不佳，信息密度高时可读性差。
- 输入区缺少常见的回车发送交互（同时需要兼容中文输入法 IME，避免误发送）。

## What Changes
- Secretary 抽屉整体更大、更适合阅读：
  - 桌面端加宽（不再像小弹窗）
  - 移动端接近全屏（更符合“抽屉”预期）
- Chat 视图改为“内容优先”布局：
  - 消息列表占满可用高度并可滚动
  - 输入区固定在底部，突出输入框与发送按钮
- Chat 消息渲染 Markdown（含代码块/列表/表格；mermaid 继续沿用现有渲染能力）
- 输入框支持回车发送（Shift+Enter 换行；IME composing 时 Enter 不发送）

## Impact
- 仅 Web UI 改动；不改后端 API/数据模型。
- 兼容现有 Live Drawer（不影响 Live 的功能，只提升共用样式的可用性）。
